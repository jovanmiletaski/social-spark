# Social Spark

Social Spark is a SaaS web application for tracking and analyzing social media performance in one centralized dashboard.

## 🚀 Features

* Unified dashboard for multiple social media platforms
* Key performance metrics (engagement, reach, growth)
* AI-powered suggestions for improving content performance
* Clean and modern UI

## 🛠 Tech Stack

* React + TypeScript
* Vite
* Tailwind CSS
* AI integrations (OpenAI or similar APIs)

## 💡 My Role

* Designed and built the user interface
* Structured the dashboard layout and components
* Integrated APIs and handled data display
* Implemented AI-based suggestions for user insights

* Working with APIs and async data
* Designing SaaS-style dashboards
* Structuring scalable UI components
